# Достань идею с полки

Пет-проекты в эпоху нейросетей: из задумки в работающий продукт.

Презентация для внутренней встречи разработчиков RNDS: SyncScore, CloudMus, OpenAPI Yagen, Keeplet, KSL
и консольные утилиты — как нейросети помогают доводить пет-проекты до релиза.

**Смотреть:** https://navrocky.github.io/petcoding-presentation/

## Управление

| Клавиша | Действие |
|---|---|
| → ↓ Space PgDn Tab | следующий слайд |
| ← ↑ PgUp Shift+Tab | предыдущий слайд |
| O | обзор всех слайдов (клик по слайду — перейти к нему) |
| B или `.` | затемнить экран |

Лучше всего смотреть в Chromium-браузерах в полноэкранном режиме (F11).

## Устройство

Статический сайт без сборщиков и зависимостей на [impress.js](https://github.com/impress/impress.js) 1.1.0.

- `index.html` — все слайды; положение каждого в 3D-пространстве задают атрибуты `data-x/y/z`,
  `data-scale`, `data-rotate*`. Слайды идут по спирали по часовой стрелке, уходя в глубину.
- `css/style.css` — оформление в стиле [cloudmus.app](https://cloudmus.app): тёмное стекло, оранжевый акцент.
- `js/main.js` — параллакс фоновых орбов, прогресс, летящие облака CloudMus, титры бэклога,
  показ только соседних слайдов (±2) для производительности.
- `img/`, `fonts/` — картинки и шрифты (Rubik, JetBrains Mono), всё локально.

## Локальный запуск

Открыть `index.html` в браузере — сервер не нужен.

## Публикация

`./build.sh` собирает сайт в `dist/`. При пуше в `main` GitHub Actions
(`.github/workflows/pages.yml`) собирает его и публикует на GitHub Pages.
